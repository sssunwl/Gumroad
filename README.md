# Gumroad — Suniverse 工具與模板據點

對外頁：https://sssunwl.github.io/Gumroad/

## 這是什麼

收整「可以拿出去賣或免費放出去」的工具與模板。目前這個 repo 只有一頁靜態
`index.html`（GitHub Pages 來源 = `main` 分支根目錄）。

## 規則

- **只列真的做完的東西。** 未完成的放「準備中」區，寫清楚在做什麼，
  **不放價格、不放購買按鈕**——沒有真的能買的東西之前，不製造「好像買得到」的錯覺。
- 產品文案素材另外放：IG Carousel 的文案與定價階梯在 `saidio/GUMROAD_LISTING.md`
  （上架前所有 `〔〕` 待填欄位都要改掉）；AI OS 入門包的內容在
  `AINewsSuni/ai-academy/aios-starter-kit/`。
- 真的上架時才把價格與 Gumroad 購買連結加進 `index.html`。

## 部署

推 `main` 就會自動重建 Pages，不用另外做事。
